# Assets and dependencies

The train, passenger geometry, props, animation, ocean shaders, and fallback sky are defined in the project's source. `public/landscape-panorama.jpg` is an image generated for this project and is supplied with the original project files under the project license.

Dependencies retain their own licenses:

| Dependency | Purpose | License | Source |
| --- | --- | --- | --- |
| Three.js | Rendering and controls | MIT | https://github.com/mrdoob/three.js |
| ws | Realtime transport | MIT | https://github.com/websockets/ws |
| Vite | Development and bundling | MIT | https://github.com/vitejs/vite |
| Playwright | Automated browser validation | Apache-2.0 | https://github.com/microsoft/playwright |
| Prettier | Source formatting | MIT | https://github.com/prettier/prettier |

See `package-lock.json` and each installed package's license for the exact dependency tree. Screenshots in `docs/` show this application with generated demo visitors and anonymous local test sessions.
